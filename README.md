# Report 華碩線上商店資安事件
 - 姓名:陳宥閎
 - 學號:411424033
 - 系級:資工二A
## 事件 : 華碩表示發現線上購物商店 ASUS eShop 部分環境出現未授權存取    
## 曝光 : KitGuru 於 2026 年 9 月 23 日率先公開華碩發給受影響客戶的官方通知信，The Register及Tom’s Hardware也進行了相關的報導
## 外洩資料與範圍 : 華碩信中表示，調查顯示部分客戶訂單資訊可能遭到存取，包括聯絡資訊與訂單紀錄
## 未受影響部分 : 華碩官方特別強調，使用者信用卡卡號、銀行帳戶或其他金融付款資訊並未受到影響
## 未解之謎 : 華碩並未對外公開具體受影響的客戶人數及涉及哪些國家或地區等資訊
## 心得 : 看完新聞後我比較擔心的是使用者的部分個人資料在外洩後，感覺會很容易遭到有心人士利用進行詐騙等行為，台灣根本就是詐騙王國，而且華碩雖然履行了告知義務，但對於受影響的人數、具體區域與駭客手法皆避而不談，這樣的行為難免會讓使用者對華碩在資安控管的信任度降低
